# AGENTS.md

## Planning

- When the request is complex (multiple files, multiple steps, or design decisions), first present a brief plan: goal, ordered steps, affected files, and risks. Then execute.
- For trivial changes (one file, text, rename), execute directly, without a plan.
- If the user disagrees with the plan, adjust before acting.

## Reasoning

- Keep your reasoning brief: tasks are bounded and well specified. Go straight to implementation without exploring alternatives.
